# PlexPlus RetroTV hosted player

Public static YouTube player for the Samsung/Tizen PlexPlus app, hosted using GitHub Pages. This repository is intentionally limited to the player page and its bridge; it is not a Plex server, app update service or private media library.

Only YouTube video IDs, playback/picture/volume controls and playback state cross the player bridge. Never send Plex tokens, update codes, server addresses, library listings, cookies or signing keys to this page or commit them here.

The `bridgeToken` URL value is a random per-frame nonce generated by the TV app, not a Plex login or a reusable account credential. It identifies messages for that player instance. The page accepts messages only from its parent frame with the matching nonce and valid command schema. Responses bind to the validated parent's exact origin; opaque packaged-app origins necessarily use the wildcard destination after validation.

A Content Security Policy restricts scripts/frames to the player origin and required YouTube providers, and disables objects, forms and base overrides. Third-party YouTube requests remain part of normal embedded playback.

## Test before deployment

```bash
node --test tests/*.test.cjs
```

Pushing to the published branch can update the live GitHub Pages player. Do not commit debug pages, local configuration or private account data. Full source ownership/staging is in the main PlexPlus repository's `tizen/hosted-player/` and `tizen/tools/stage-hosted-player.js`; keep them aligned.
